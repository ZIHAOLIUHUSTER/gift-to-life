# 阶段 1 方法

## 架构分层
- `core/model/`: Entry/EntryTag 实体 + EntryType/TagType 枚举
- `core/database/`: Room Database + DAO + TypeConverters
- `core/database/di/`: Hilt AppModule（提供 Database、DAO、Repository）
- `feature/record/`: RecordViewModel + RecordScreen + 子组件

## 数据流
1. UI → ViewModel.save(content)
2. ViewModel → Repository.save(entry) → EntryDao.insert()
3. Room 自动通知 Flow → UI 自动刷新列表

## 设计决策
- 普通闪念与总结统一建模（Entry.type 区分）
- 标签采用独立表 + 外键级联删除
- 编辑使用 ModalBottomSheet，不切换全屏
- 搜索筛选在 UI 层过滤（阶段 3 扩展到 DB 查询）
