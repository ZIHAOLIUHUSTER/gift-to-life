# 阶段 3 方法

## 查询逻辑下沉
- EntryQuery 参数对象统一管理所有筛选条件
- EntryDao.searchByContent 做数据库级 LIKE 搜索
- EntryTagDao.getEntryIdsByTags 标签反查
- EntryRepository.filterEntries 组合多条件筛选
- ViewModel 通过 flatMapLatest 监听 entryQuery 变化自动重新查询

## UI 筛选条
- 搜索模式：TopAppBar 变搜索框 + FilterBar（标签 Chip + 有图 Chip + 清除）
- 非搜索模式：正常 EntryComposer
- 关闭搜索自动清空 EntryQuery
