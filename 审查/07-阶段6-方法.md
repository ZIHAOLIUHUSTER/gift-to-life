# 阶段 6 方法

## AI 网络层
- Retrofit + OkHttp，OpenAI 兼容 Chat Completions API
- AiClient：动态读取 DataStore 配置创建 Service，支持 text + vision
- 视觉模型：base64 编码图片 → image_url 发送

## 后台任务
- HiltWorker (TagWorker)：约束网络连接，retry 策略
- 流程：纯图记录 → vision 模型生成描述 → 标签模型分类
- parseTags：解析中文标签名 → TagType 枚举

## Prompt
- 标签：系统角色 + 4 个标签定义，要求只输出标签名
- 视觉：一句话描述，不超过 30 字
