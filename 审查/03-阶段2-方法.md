# 阶段 2 方法

## 图片存储策略
- 选图后立即复制到 `filesDir/images/` 私有目录
- UUID 文件名 + MIME 类型推断扩展名
- Entry.imagePath 存储绝对路径，Coil 从 File 加载

## Photo Picker 集成
- 使用 `ActivityResultContracts.PickVisualMedia` + ImageOnly
- 共用同一个 launcher，通过 `editingImageEntryId` 区分新增/替换模式

## UI 组件
- EntryComposer: 选图按钮 → 缩略图预览 → 保存时复制
- EntryCard: 图片缩略图在文字上方，点击 → ImagePreviewDialog
- EditEntryBottomSheet: 查看大图 / 删除 / 替换 三个操作
