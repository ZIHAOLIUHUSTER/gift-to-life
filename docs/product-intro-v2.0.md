# Gift To Life v2.0 — 产品介绍

## 概述

Gift To Life 是一款极简 Android 个人闪念记录工具。像在旧便签纸上随手写下一句话，它安静、温暖、不打扰你，只在需要的时候帮你找回那些可能被遗忘的瞬间。

本版本经过 15 个任务的系统性数据止损、功能兑现和性能扩容，现已具备作为长期日记工具的可靠性。

---

## 一、快速记录

### 文本记录
打开即用，输入框聚焦键盘自动弹出，写完后点"保存"。支持多行输入。

### 图片记录（纯图可保存）
可从相册选择图片，或直接拍一张。哪怕一个字都不写，纯图片也能独立保存——视觉模型会自动生成一句话描述，让图片也能被搜索、被标记、被总结。

图片自动压缩为 WebP 格式（质量 85%，最大 1920px），1200 万像素原图约 500KB-1.5MB。压缩在后台执行，不阻塞界面操作。

### 图文混合
纯文字可后补图片，纯图可后补文字。一切在编辑弹层中完成，不需跳转页面。

### 从其他 App 分享进来
在浏览器、备忘录、相册等 App 中选择"分享" → 选 Gift To Life，文字和图片自动填入输入区，编辑后保存即可。即使 App 未启动也能接收分享；前台再次分享即时更新输入区。

### 桌面快捷入口
将 Widget 添加到桌面，点击一键打开 App 开始记录。

## 二、AI 智能辅助

### 自动打标签 🏷️
每条记录保存后，AI 自动从四个标签中选择 1-2 个：**闪念**（灵感想法）、**事记**（事件记录）、**情绪**（感受情感）、**知识**（思考信息）。编辑内容或换图后会重新打标签。

**并发安全：** 如果你在 AI 打标签的同时修改了记录，AI 的结果会被自动丢弃，绝不会覆盖你的手工编辑或手工标签。

### 图像识别 👁️
纯图记录自动调用视觉模型生成一句话图片描述，描述会参与标签和总结生成。图片描述仅用于 AI 增强，不在卡片上直接显示，保持界面简洁。

### 每周总结 📝
每周一可生成**上周**（周一到周日）的总结。两种风格随机切换：
- **时光切片**：诗意风格，找到那段日子最闪光的碎片
- **情绪天气**：像一本私人手帐，分析情绪起伏和变化

非周一只能查看历史总结，不能生成新总结。超过 3 条记录才可生成。重新生成会覆盖同周期已有总结。

未来版本将支持在指定日期补生成错过的总结。

### 每月总结 ✉️
每月 1 号可生成**上月**的总结。采用"老友来信"风格——用温暖真诚的口吻，以"亲爱的："开头，像一位老友在回顾你这个月的生活。

### 输入保护
总结输入采用 48,000 字符预算 + 每条 2,000 字符上限，通过近期优先 + 等距采样保证长周期下也不会 token 溢出。输入不足 3 条时直接拒绝生成，不浪费 API 调用。

### 模型配置与测试
支持 OpenAI 兼容 API。三个模型独立配置：
- **标签模型**（轻量即可，仅需文本分类）
- **总结模型**（需要较强文本理解力，建议推理模型）
- **视觉模型**（用于识别纯图片记录）

每个模型可单独测试连通性，成功显示绿色✓，失败显示红色✗和错误原因。

模型配置支持独立导入/导出（JSON 格式），不含 API Key——保护你的凭据。

## 三、回忆与探索

### 随机回顾卡片 🎲
回忆页顶部展示一张内容驱动高度的随机回顾卡片。带装饰引号「」，标签和时间居中排列，像翻开一本旧日记。点击卡片可查看全文和图片。

卡片自适应：短内容保持整洁、长内容可滚动（最多 500dp），按钮始终固定在底部不被挤走。图片以 16:9 比例显示，窄屏和字体放大自动适配。

### "再抽一条"
不满意当前回顾？点"再抽一条"，随机换一条记录。

### 历史总结归档
所有生成的周/月总结按时间倒序归档，卡片上标注时间范围（如"7/7 - 7/13"或"7月"）和生成时使用的模型名称。

---

## 四、搜索与筛选

### 全文搜索
点击搜索图标进入搜索模式，输入关键词实时过滤。搜索在数据库层执行 LIKE 查询，不依赖全量内存扫描。

### 标签筛选
四个标签 Chip 可多选组合筛选。支持 FlowRow 自适应换行，窄屏和大字体不会裁剪。

### 图片筛选
三态切换：全部 → 有图 → 无图。

### 状态安全
关闭搜索时自动重置所有筛选条件（包括搜索词、标签、图片、时间范围），不会出现暗中过滤。

## 五、数据管理

### 导出备份（v2 ZIP 格式）
将所有记录（含标签、图片、时间戳、软删除状态、总结元数据）导出为 `.gtlbackup` ZIP 文件。格式：`manifest.json` + `images/` 目录。图片以原始 WebP 格式存储，不做二次编码。

### 导入恢复（校验先于写入）
导入前先完整校验：
- 格式识别（自动区分 v1 JSON 和 v2 ZIP）
- 版本兼容性检查
- 条目数量确认
- 图片完整性校验

**校验失败不修改现有数据库**——你的数据绝不会被损坏的备份破坏。旧 v1 JSON 格式仍可导入（只读兼容），导入时提示"旧版备份缺少部分元数据，正文、图片和标签仍会导入"。

### 模型配置导入/导出
标签、总结、视觉模型配置可独立导入导出为 JSON。API Key 不会被导出。

### 回收站（完整恢复）
删除的记录进入回收站，保留完整标签信息。可逐条恢复（含标签），也可一键清空。清空回收站时同步删除关联图片文件，避免磁盘空间泄漏。

## 六、隐私与安全

### 数据存储
所有数据存储在手机本地私有目录（`filesDir/`）。不上传任何数据到第三方，除非你选择使用云 API 服务。

### 云端备份保护
系统自动备份排除 API Key、日记数据库和图片目录。即使手机自动备份至云端，你的私密数据也不会被上传。

### API 调用
AI 调用在你配置的 API 服务器上完成。API Key 使用系统 SharedPreferences 存储，不随系统备份同步。

### 图片文件生命周期
永久删除、清空回收站、换图和删图时，关联的图片文件都会被删除。不再引用的图片可通过"清理无主图片"功能定期回收。

## 七、性能与扩展性

### 目标容量
设计目标为 **10,000 条记录**下仍可流畅使用：

| 指标 | 目标 |
|------|------|
| 进入记录页首屏可用 | < 500ms |
| 首屏数据库查询 | < 100ms |
| 搜索词到结果更新 | < 500ms |
| 随机回顾 | < 100ms |
| 列表滚动 200 条 | 无崩溃，无明显停顿 |

实际容量取决于设备和记录长度。1000 条记录在大多数设备上体验流畅。

### 架构优化
- **Paging 3**：列表按 30 条分页加载，不一次性加载全部
- **SQL 下推**：筛选条件（搜索、标签、日期、图片）在数据库层执行，带参数绑定
- **索引优化**：关键查询路径建了 3 个复合索引
- **总结输入预算**：48K 字符上限 + 采样策略，防止超长输入

## 八、技术细节

| 项目 | 规格 |
|------|------|
| 最低系统 | Android 8.0 (API 26) |
| App 大小 | ~1.7MB（Release） / ~18MB（Debug） |
| 本地数据库 | Room + SQLite（带无损迁移方案） |
| 图片存储 | 私有目录，WebP 压缩（max 1920px, 85% 质量） |
| AI 接口 | OpenAI 兼容 Chat Completions API |
| 架构模式 | MVVM + Repository + Paging 3 |
| 依赖注入 | Dagger Hilt |
| 后台任务 | WorkManager（唯一任务 + 版本校验防覆盖） |
| 备份格式 | v2 ZIP（`.gtlbackup`），兼容 v1 JSON |

### 数据库升级
从 version 1、2、3 到当前 version 4 均有自动化 Migration，不会因升级 App 丢失数据。早期版本（无 `imageDescription` 列）通过 PRAGMA 检测条件加列，确保兼容两种历史 schema。

## 九、设计理念

- **安静不打扰**：暖白背景、低饱和配色、无广告无推送
- **先预览再编辑**：点击卡片先看到完整内容，确认要改再点"编辑"。删除按钮在预览层（与编辑对称），有确认弹窗
- **本地优先、AI 可失败**：AI 不在保存路径上，失败不影响记录。AI 结果不能覆盖你的修改
- **数据安全第一**：备份校验先于写入、导入确认弹窗、软删除可恢复、图片文件同步清理
- **文章体总结**：不用冷冰冰的列表，用散文诗、手帐、书信的方式回顾你的生活。周报随机切换风格，月报固定老友来信
