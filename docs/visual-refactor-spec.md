## 0. 实现模型先读

### 0.1 一句话任务

这不是一次换色、换圆角或增加装饰的美化，而是一次**视觉信息、容器数量、提示文字和操作路径的减法重构**。

完成后，用户应该自然感到：

> 打开就能写；写完马上离开；回来一眼看懂；不需要的功能不会主动出现。

### 0.2 决策优先级

发生冲突时，按以下顺序处理：

1. 用户在当前对话中的明确要求；
2. 本执行规格中的 **MUST / 禁止项 / 阶段闸门**；
3. 当前工作区源码的真实行为与数据安全约束；
4. `docs/dev-summary.md`、`docs/ai-chain.md` 等当前文档；
5. 旧截图、旧设计稿和历史说明。

发现冲突时不要自行折中；保留安全行为，并在交付说明中列出冲突。

### 0.3 规范词义

- **MUST**：本轮必须满足，不允许实现模型自行换方案；
- **SHOULD**：默认这样实现，只有明确的可用性或平台原因才能偏离，并需说明；
- **LATER**：方向已定，但属于后续交互阶段，本轮视觉阶段不得顺手实现；
- **禁止**：即使实现更方便也不能采用。

## 1. 设计定位

### 1.1 工作名称

**温润克制的器物感**（Quiet Object Minimalism）。

“玉”只是一种气质隐喻，不是拟物主题。

### 1.2 “玉”的正确转译

- **中正**：对齐稳定、比例端正、层级清楚，一屏只有一个焦点；
- **温润**：低饱和、低刺激、边界柔和但清楚，反馈轻而明确；
- **小巧**：入口少、默认值合理、常用任务短，高级能力不铺满屏幕；
- **克制**：少显示元信息，少写解释，少制造状态，少让用户做决定。

### 1.3 禁止的错误转译

禁止通过以下方式制造“玉感”或“高级感”：

- 玉纹、石材纹理、玻璃拟态、高光渐变；
- 把所有界面改成翡翠绿；
- 书法字体、新中式纹样、印章等装饰；
- 大量留白配小字号；
- 低对比灰字；
- 所有控件都做成圆润胶囊；
- 增加插画、徽章、卡片和动效来“丰富层次”。

### 1.4 产品一句话

> Gift To Life 是一件低噪声的私人记忆器：记录一拍即得，回看一眼即懂，AI 在后台工作，不站到内容前面。

## 2. 目标、非目标与硬约束

### 2.1 本次目标

1. 降低默认页面的容器数量和主色面积；
2. 让正文内容成为第一视觉层级；
3. 统一中文排版，不再混用未定义的 Material 默认字阶；
4. 让搜索、筛选、AI 高级设置按需出现；
5. 保持记录保存、浏览和回顾路径短；
6. 在不破坏功能的前提下，使三个主页面形成同一种安静、端正的节奏。

### 2.2 非目标

本轮不做：

- 新皮肤、新品牌色或大范围调色；
- 新字体依赖；
- 新功能或新主导航；
- 数据库、备份、AI 输出契约重构；
- Material 3 的全面自研替代；
- 为追求统一而重写 ViewModel、Repository 或网络层；
- 横屏、平板或整套响应式架构重做；
- 把 Gift 做成古风、手帐或拟物玉器 App。

### 2.3 产品能力必须保留

- 主入口：**回忆 / 记录 / 设置**；
- 记录、图片、分享接入、搜索、筛选；
- 随机回顾、那年今日、周志、月志；
- 六套皮肤与浅色/深色/跟随系统；
- AI 标签、图片识别和总结；
- 备份与恢复、回收站、Widget、分享和深链；
- 本地优先、无账号、无社交、无云同步的产品定位。

### 2.4 视觉硬约束

- **MUST**：中性画布与内容占绝大多数面积；
- **MUST**：普通页面同一时刻只有一个主视觉焦点、一个主要填充按钮；
- **MUST**：主色只用于主行动、选中态、链接、光标、细线或小标记；
- **禁止**：整页、整张内容卡或整行列表使用主题色填充；
- **禁止**：用多个大色块表达层级；
- **禁止**：普通内容卡使用阴影；
- **MUST**：正文与次级文字保持现有 WCAG 对比度标准；
- **MUST**：触控目标至少 48dp；
- **MUST**：1.3x 系统字体下关键文字和按钮不裁切。

### 2.5 交互硬约束

- 保存记录仍须先本地完成，AI 不得进入保存关键路径；
- 普通新建记录不得增加确认或中间页面；
- 只有危险或不可逆动作使用确认弹窗；
- 普通路径不得展示服务商内部参数、思考过程或协议细节；
- 控件折叠后必须仍然可发现，不能以“克制”为由藏掉必要能力；
- 视觉阶段只能调整局部 UI 状态，不得偷偷改变数据语义和后台任务行为。

## 3. 全局视觉系统

### 3.1 材质关系

全 App 只使用四层视觉关系：

1. **纸面画布**：当前皮肤的 `background/surface`；
2. **白玉内容面**：当前皮肤的 `surfaceContainer`；
3. **墨字**：`onSurface/onSurfaceVariant`；
4. **青松落款**：`primary` 的小面积点睛。

默认青松仍是品牌皮肤。六套现有色值已经通过对比度验收，**MUST 不因本轮审美调整而重算整套色板**。本轮优先改变颜色的面积、频率和位置。

### 3.2 色彩用途

| Token | 唯一职责 |
|---|---|
| `background` / `surface` | 页面画布、顶栏背景 |
| `surfaceContainer` | 必要的主内容面、分组面 |
| `surfaceVariant` | 输入区或极轻的次级状态，不作普通卡片底 |
| `primary` | 主按钮、选中态、链接、光标、小标记 |
| `primaryContainer` | 很小的选中状态；禁止整卡填充 |
| `zone` | 品牌细节或小提示条；禁止大圆形空状态和整卡背景 |
| `onSurface` | 正文与重要标题 |
| `onSurfaceVariant` | 时间、说明和元信息 |
| `LifeStatus` | 成功、危险、警告、信息；不得拿来区分装饰性卡片类型 |

量化规则：

- 除主按钮外，普通内容屏不得出现高度超过 48dp 的连续 `primary` 或 `primaryContainer` 大色面；
- 主色填充在普通内容屏的感知面积 SHOULD 不超过约 5%；
- 标签默认使用中性文字或中性容器，不按“闪念/事记/情绪/知识”分别上色；
- 总结的事实、引语、洞察不是成功/警告/信息状态，禁止分别使用 `LifeStatus.Success/Warning/Info` 装饰。

### 3.3 排版映射

不得引入新字体依赖。`GiftTypography` MUST 覆盖项目实际使用的 `headline*`、`title*`、`body*`、`label*`，避免回落到 Material 默认值。

建议按以下精确映射实现：

| Material 角色 | 字号 / 行高 | 字重 | 用途 |
|---|---:|---|---|
| `headlineLarge` | 26 / 34sp | 600 | 沉浸式页面大标题，极少使用 |
| `headlineMedium` | 20 / 28sp | 500 | 大分组标题 |
| `titleLarge` | 20 / 28sp | 500 | TopAppBar 标题 |
| `titleMedium` | 16 / 24sp | 500 | 卡片/列表标题 |
| `titleSmall` | 14 / 22sp | 500 | 紧凑标题 |
| `bodyLarge` | 16 / 24sp | 400 | 记录正文、主要阅读内容 |
| `bodyMedium` | 14 / 22sp | 400 | 设置说明、次级正文 |
| `bodySmall` | 12 / 18sp | 400 | 时间、摘要、元信息 |
| `labelLarge` | 14 / 20sp | 500 | 按钮文字 |
| `labelMedium` | 12 / 18sp | 500 | 标签、页脚 |
| `labelSmall` | 11 / 16sp | 400 | 脚注、最弱状态 |

统一规则：

- 中文字距设为 0；
- 禁止普遍使用 700；
- 600 只给极少数页面大标题；
- 页面层级主要靠字号、留白和明度，不靠连续加粗；
- 正文不得为了显得精致而低于 14sp；
- 数字与日期应保持稳定宽度，避免布局跳动。

### 3.4 形状

沿用现有语义 token：

| 语义 | 值 | 用途 |
|---|---:|---|
| input | 6dp | 输入框、图片内层 |
| small | 8dp | 小按钮、筛选项、紧凑控件 |
| card | 10dp | 普通内容面、分组面 |
| action | 12dp | 主按钮、主要操作容器 |
| sheet | 16dp | BottomSheet、Dialog、沉浸阅读面 |
| pill | 999dp | 只用于真正的标签、状态或页码点 |

明确决策：

- 普通内容卡统一 10dp；
- BottomSheet / Dialog 统一 16dp；
- 总结牌桌属于大型阅读容器，V4 时从 20dp 收敛到 16dp；
- 底栏选中态取消大胶囊；
- 不新增其它圆角档位。

### 3.5 间距与密度

> **2026-09-27 v4.6.1 修订**：下表旧值（页面 16dp / 内容 16dp / 紧凑行 16×12dp）在真机上偏挤，
> 已改为 `PageGutter = 22dp`、`ContentPadding = 18dp`、`RowPaddingV = 16dp`（见 §0.5 第 3 条与 `core/ui/theme/Spacing.kt`）。

- 基础网格：4dp；
- 页面水平边距：16dp（→ 22dp）；
- 页面一级区块间距：24dp；
- 组内间距：8dp 或 12dp；
- 普通内容内距：16dp（→ 18dp）；
- 紧凑列表内距：水平 16dp、垂直 12dp（→ 水平 22dp、垂直 16dp）；
- 图标默认 24dp，行内 20dp；
- 所有可点击图标仍须放在至少 48dp 的触控区域中。

实现时不需要为每个间距新建 token 类，但同一组件的**布局尺寸（dp）**不得混入没有语义来源的随意值；文字行高不受此句限制。

### 3.6 边界与阴影

- 普通内容面：0dp 阴影；
- 明确边界：`outlineVariant` 0.5–1dp；
- 分隔线：`outlineVariant`，只作结构提示；
- 唯一允许的阴影例外：V4 的当前总结牌可使用不超过 4dp 的轻阴影，以维持真堆叠层次；邻牌仍为 0dp；
- 禁止渐变和多层阴影。

### 3.7 顶栏与底栏

#### 顶栏

- 使用紧凑 `TopAppBar`，禁止 `LargeTopAppBar`；
- 背景与页面画布一致；
- 标题使用 `titleLarge`；
- 每侧只放必要操作；
- 不加阴影或大色块。

#### 底栏

MUST 改为：

- 背景使用 `surfaceContainer`；
- 顶部用一条极弱分隔线与画布区分；
- 选中项只改变图标和文字颜色，不使用背景胶囊或额外指示线；
- `indicatorColor = Color.Transparent`；
- 未选中项使用 `onSurfaceVariant`；
- 保持 48dp 触控目标和系统导航安全区。

### 3.8 图标与动效

- 保留 Material Rounded 图标体系；
- 文字已足够清楚时不再添加装饰图标；
- 图标只表达动作或类别，不表达“氛围”；
- 使用现有 `LifeMotion`：150 / 200 / 250ms；
- 禁止弹跳、夸张缩放、持续呼吸和背景动画；
- Crossfade 只用于内容替换，不用于每个列表元素。

## 4. 信息与操作预算

### 4.1 信息优先级

所有页面统一遵循：

> **正文/核心内容 > 当前动作 > 时间/状态 > 标签 > AI、模型和统计元数据。**

### 4.2 一屏预算

普通页面默认最多拥有：

- 一个页面标题；
- 一个主视觉焦点；
- 一个主要填充按钮；
- 一组低强调次级操作；
- 一段必要说明。

出现多个大卡、多个按钮组、多组 chip 和多段说明时，先删减或按需折叠，不通过继续调色解决。

### 4.3 可量化的默认态

| 页面 | 默认可见的卡片状内容面 | 默认主色填充按钮 | 默认展开的高级控件 |

| 回忆页 | 2（随机回顾 + 三入口分组） | 0 | 0 |

### 4.4 常用路径目标

| 任务 | 目标路径 |

| 新建文字记录 | 打开记录页 → 输入 → 保存 |

## 5. 页面执行规格

### 5.1 记录页

#### 5.1.1 目标

记录页第一眼只表达：**现在可以写。**

#### 5.1.2 目标结构

```text
┌────────────────────────────┐
│ 记录                    搜索 │
├────────────────────────────┤
│ ┌──── 唯一输入内容面 ─────┐ │
│ │ 此刻的想法……             │ │
│ │ [可选图片预览]            │ │
│ │ 图片                 保存 │ │
│ └────────────────────────┘ │
│                            │
│ 第一条正文……                │
│ 事记 · 9月26日 18:30         │
│ ─────────────────────────  │
│ 第二条正文……                │
│ 9月25日 22:10                │
│ ─────────────────────────  │
└────────────────────────────┘
```

#### 5.1.3 `EntryComposer`（MUST）

- 输入器是页面唯一主要内容面：`surfaceContainer`、10dp、0 阴影、弱描边；
- 禁止“外层 Card + 内层有色/描边 TextField”的双重容器；
- 采用单一输入面：文字输入区域透明，聚焦用光标或外边界轻微变色表达；
- 最小输入高度 56dp（4.7.0），最大高度 200dp；
- “图片”是低强调文字/图标按钮，保持 48dp 触控区；
- “保存”是该屏唯一填充主按钮，最小高 48dp、12dp 圆角；
- 保存中只在原按钮内显示进度，不额外覆盖页面；
- 图片预览仍在输入面内，使用 8dp 内层圆角；
- 图片关闭按钮必须有可识别的对比底或 scrim，不能直接用白图标压在浅图上。

#### 5.1.4 `EntryCard`（MUST）

普通记录列表改成**连续时间流**，不再每条一张独立白卡：

- 外层使用透明 Surface 或普通 Column，背景继承纸面；
- 每条记录水平 16dp、垂直 12dp；
- 条目之间使用弱分隔线；
- 正文使用 `bodyLarge`，最多 4 行；
- 图片存在时放在正文上方，最大高 160dp，8dp 圆角；
- 元信息合并为一行纯文字，例如 `事记 · 知识 · 9月26日 18:30`；
- 记录列表里的标签不再使用有底色的绿色小卡；
- 标签最多显示 2 个，剩余使用 `+N`；
- 时间与标签统一 `bodySmall/onSurfaceVariant`；
- 搜索命中高亮保留，但透明度降低到不盖住文字的程度；
- 保持现有行为：点击正文区域打开预览，点击图片打开图片预览。

#### 5.1.5 搜索与筛选（MUST）

默认搜索态只显示：搜索输入框、关闭、一个筛选入口。

- 删除常驻的“4 个标签 chip + 3 个图片 chip + 清除筛选”；
- 筛选入口使用 `FilterList` 类图标，并在有激活条件时显示数量或小点；
- 点击筛选后打开 `ModalBottomSheet`；
- 面板内再显示标签和图片筛选；
- 面板关闭后，结果立即生效；
- 搜索页主体只展示结果；
- 有筛选时，在搜索栏下显示一行摘要，例如 `闪念 · 有图`，单行省略，右侧提供 `清除`；
- “清除筛选”只在至少一个筛选条件激活时出现；
- 关闭搜索仍按当前逻辑清空搜索与筛选状态。

#### 5.1.6 空状态

- 普通记录页无数据：`还没有记录` / `从此刻的一句话开始`；
- 搜索无结果：`没有找到记录` / `换个关键词或调整筛选`；
- 不用大色块或大插画。

### 5.2 回忆页

#### 5.2.1 目标

#### 5.2.2 目标结构

```text
│ 回忆                        │
├────────────────────────────┤
│ ┌──── 随机回顾（主焦点） ─┐ │
│ │ 随机回顾                  │ │
│ │                            │ │
│ │ 一段真正值得看的正文……    │ │
│ │ [可选图片]                 │ │
│ │                            │ │
│ │ 事记 · 9月26日     再抽一条 │ │

│                            │
│ ┌──── 单一分组内容面 ─────┐ │
│ │ 周志       上周 · 已写好  › │
│ │ ─────────────────────── │ │
│ │ 月志       上月 · 34 条   › │
│ │ ─────────────────────── │ │
│ │ 那年今日   3 年 · 5 条    › │
│ └──────────────────────────┘ │
└────────────────────────────┘
```

#### 5.2.3 `RandomReviewCard`（MUST）

**定高外壳 + 固定内容区。切换时屏幕上不能有任何位移。**

外壳：

- 删除固定 `height(460.dp)` 的“高高空白”做法，但也**不采用“高度随内容”**；
  改用**与内容无关的定高牌框**：当前手机实现 340dp（4.7.0 保持此值），
  与总结牌桌的“定高牌框”同一道理：一致尺寸看起来是故意的，高度跳变看起来是抖动；
- 结构四段固定：[随机回顾标签] / [内容区：固定高约 200dp] / [一行弱元信息] / [分隔线 + 再抽一条]；
- 背景 `surfaceContainer`，禁止整卡 `primary.copy(alpha = ...)`；
- 10dp 圆角、0 阴影、0.5–1dp 弱描边；
- 主色只用于一个短细线、小标记或“再抽一条”文字；
- 分隔线用中性 `outlineVariant`，不用主色线。

内容区（固定高 200dp，内部自适应，**不改变外壳尺寸**）：

- 无图短文（≤ 48 字）：19–20sp 居中，垂直居中；
- 无图长文：15–16sp 左对齐，按内容区高度截断，右下角一行 `查看全文`；
- 有图：图片固定高 140dp（**永远预留这个位置**，图未加载完先用中性占位），
  下方最多 2 行文字；
- 禁止“图片加载完再把卡片撞开”的写法。

**切换稳定性（针对“再抽一条”）——以下每条都是硬要求：**

1. **只保留一份内容实例**：禁止 `Crossfade` / `AnimatedContent` 同时叠放两份完整布局；
   换条目就是直接换内容，不需要淡入淡出。
2. **卡片尺寸与内容无关**：切换前后卡片宽高完全一致，元信息行与按钮不得上下移动；
   内容区是唯一可弹性/可裁剪的元素（`weight(1f)` + 裁切），卡片内不得再出现第二个弹性占位。
3. **禁止布局溢出推挤**：长文超过内容区高时必须裁切，不得把元信息与按钮往下推。
4. **“再抽一条”永不禁用**：本地随机查询不需要 300ms 冷却；
   如需防重入，只在内部丢弃并发的重复请求，按钮的可用、颜色、文字不可变。
5. **验收标准**：连续点击 10 次，卡片不抖、不跳、不吞点击，任意两次之间的差异只应出现在内容区与元信息文字上。

其他：

- 元信息只用一行弱文字（如 `事记 · 9月24日`），不使用有底色标签；
- “再抽一条”是唯一明显的次级动作；
- `查看全文` 只在内容确实被截断时出现，禁止常驻“点击查看全文”。

#### 5.2.4 周志 / 月志 / 那年今日（MUST）

- 删除两个并列大型 `OutlinedButton`；
- 三个入口放入同一个 `surfaceContainer` 分组面；
- 每行高至少 56dp，整行可点击；
- 左侧标题，右侧一行状态和 chevron；
- 状态只展示用户关心的信息：周期、是否已有内容、记录数量；
- 不显示模型名、生成耗时或供应商；
- 原 V2 视觉阶段保留列表导航；4.7.0 已在获批 I1 阶段实现：有当前周期总结时直接进入牌桌，无总结时进入生成/历史页，历史保留独立入口。

#### 5.2.5 空状态（MUST）

- 删除包裹空状态的大 Card；
- 删除 88dp 主题色圆块；
- 可保留 20–24dp 的小星形品牌标记，使用主色或弱描边；

## 7. 文案规则

### 7.1 基本句式

- 标题用名词；
- 按钮用动词；
- 一句话只表达一个事实或动作；
- 成功提示使用“已 + 动词”；
- 进度提示使用“正在 + 动词……”；
- 错误提示使用“发生了什么 + 下一步”；
- 普通界面不解释实现原理。

### 7.2 保留的语气

- `此刻的想法……`
- `已记录`
- `再抽一条`
- `上周的你`

### 7.3 收敛示例

| 当前长说明 | 默认界面 | 详细说明位置 |
|---|---|---|
| 后台生成上周周志和上月月志，写好后通知，各消耗一次 API | 写好后提醒你 | 自动回顾帮助说明 |

数据安全文案不因“克制”而删减；它只应出现在真正执行危险操作的时刻。

## 11. 实现模型的交付格式

每个阶段完成后只报告四项：

1. **结论**：本阶段解决了什么；
2. **改动**：哪些文件、删掉了哪些视觉噪声、为何这样取舍；
3. **验证**：测试、构建、schema 检查与可用的截图结果；
4. **风险/遗留**：哪些属于 I1–I4，没有在视觉阶段偷做。

不要只报告“统一了风格”或“更高级”。必须用可核对事实描述，例如：

- 默认记录页卡片状容器从“输入器 + 每条记录”降为仅输入器 1 个；
- 默认搜索态从 7 个常驻筛选 chip 降为 1 个筛选入口；
- 回忆页随机卡由固定 460dp 改为 340dp 稳定牌框，只有内部内容替换；
- 设置主页由 5 张入口卡改为 2 个分组面；
- AI 默认页隐藏了哪些高级项。

## 12. 最终判断标准

第一次打开 App 的人不需要读设计理念，也不需要先学习功能，就应该感到：

- 这里可以马上写下一句话；
- 页面安静，但不是空；
- 每个动作都很近；
- 内容比功能更重要；
- AI 在帮忙，但没有抢走主角位置；
- 这是一个可以长期放在手边的小东西，而不是展示功能的后台。

最后做一次反向检查：

> 如果某个改动让页面“更丰富、更有层次、更像完整产品”，但同时增加了卡片、颜色、提示、按钮、学习成本或等待，它就不符合本规格。
