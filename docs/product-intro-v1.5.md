# Gift To Life v1.5.0 — 产品介绍

## 概述

Gift To Life 是一款极简 Android 个人闪念记录工具。像在旧便签纸上随手写下一句话，它安静、温暖、不打扰你，只在需要的时候帮你找回那些可能被遗忘的瞬间。

---

## 一、快速记录

### 文本记录
打开即用，输入框聚焦键盘自动弹出，写完后点"保存"。支持多行输入。

### 图片记录
可从相册选择图片，或直接拍一张。图片自动压缩为 WebP 格式（质量 85%，最大 1920px），大幅节省存储空间——500 万像素原图压缩后通常仅 500KB-1.5MB。

### 图文混合
纯文字可后补图片，纯图可后补文字。一切在编辑弹层中完成，不需跳转页面。

### 从其他 App 分享进来
在浏览器、备忘录、相册等 App 中选择"分享" → 选 Gift To Life，文字和图片自动填入输入区，编辑后保存即可。

### 桌面快捷入口
将 Widget 添加到桌面，点击一键打开 App 开始记录。

## 二、AI 智能辅助

### 自动打标签 🏷️
每条记录保存后，AI 自动从四个标签中选择 1-2 个：**闪念**（灵感想法）、**事记**（事件记录）、**情绪**（感受情感）、**知识**（思考信息）。编辑内容或换图后会重新打标签。

### 图像识别 👁️
如果你的记录只有一张图片没有文字，视觉模型会自动生成一句话图片描述，描述会参与标签和总结生成。

### 每周总结 📝
每周一生成上周的总结。两种风格随机切换：
- **时光切片**：诗意风格，找到那段日子最闪光的碎片
- **情绪天气**：像一本私人手帐，分析情绪起伏和变化

### 每月总结 ✉️
每月 1 号生成上月的总结。采用"老友来信"风格——用温暖真诚的口吻，以"亲爱的："开头，像一位老友在回顾你这个月的生活。

### 模型配置
支持 OpenAI 兼容 API。可配置：
- API Key（密码遮罩）
- API 地址（自动补全 `/v1/chat/completions`）
- 标签模型、总结模型、视觉模型（可分别测试连通性）

## 三、回忆与探索

### 随机回顾卡片 🎲
回忆页顶部展示一张 420dp 固定高度的随机回顾卡片。带装饰引号「」，标签和时间居中排列，像翻开一本旧日记。点击卡片可查看全文和图片。

### "再抽一条"
不满意当前回顾？点"再抽一条"，随机换一条记录。

### 历史总结归档
所有生成的周/月总结按时间倒序归档，卡片上标注时间范围和使用的模型。

---

## 四、搜索与筛选

### 全文搜索
点击搜索图标进入搜索模式，输入关键词实时过滤。

### 标签筛选
四个标签 Chip 可多选组合筛选。

### 图片筛选
三态切换：全部 → 有图 → 无图。

---

## 五、数据管理

### 导出备份
将所有记录（含标签、图片 base64 编码）导出为 JSON 文件。图片内嵌在 JSON 中，一个文件即可完整备份。

### 导入恢复
选择 JSON 文件导入。导入前会弹窗确认"将清空所有现有记录"，确认后替换式导入，保留原始时间戳和图片。

### 模型配置导入/导出
AI 配置（API Key、地址、三个模型名）可独立导入导出，方便在不同设备间迁移。

### 回收站
删除的记录进入回收站，可恢复或永久清空。

## 六、技术细节

| 项目 | 规格 |
|------|------|
| 最低系统 | Android 8.0 (API 26) |
| App 大小 | ~18MB |
| 本地数据库 | Room + SQLite |
| 图片存储 | 私有目录，WebP 压缩 |
| AI 接口 | OpenAI 兼容 Chat Completions API |
| 架构模式 | MVVM + Repository + Flow |
| 依赖注入 | Dagger Hilt |
| 后台任务 | WorkManager（标签/视觉异步处理） |

### 隐私
所有数据存储在手机本地（`filesDir/`）。AI 调用在你配置的 API 服务器上完成。不上传任何数据到第三方，除非你选择使用云 API 服务。

---

## 七、设计理念

- **安静不打扰**：暖白背景、低饱和配色、无广告无推送
- **先预览再编辑**：点击卡片先看到完整内容，确认要改再点"编辑"
- **删除确认**：每次删除都有确认弹窗，不用担心误操作
- **文章体总结**：不用冷冰冰的列表，用散文诗、手帐、书信的方式回顾你的生活
