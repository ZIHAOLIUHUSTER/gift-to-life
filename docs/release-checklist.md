# Gift To Life 发布检查清单

## 安装与升级

- [ ] 全新安装（无旧数据）→ 正常启动
- [ ] version 1 数据库升级 → 数据无损（早期 v1 无 imageDescription）
- [ ] version 3 数据库升级 → 数据无损（含 isDeleted/summaryModel）
- [ ] 卸载后重装 → 数据清空，正常启动

## 核心记录

- [ ] 文本记录保存、列表显示、时间戳正确
- [ ] 纯图记录保存（无文字）→ 成功
- [ ] 图文混合保存 → 图片预览正确
- [ ] 编辑文字 → 保存后更新
- [ ] 编辑标签 → 标签即时显示
- [ ] 换图 → 旧图删除，新图显示
- [ ] 删除图片 → 图片文件清理
- [ ] 5 行截断 → 点击预览全文

## AI 标签

- [ ] 配置有效 API Key → 保存后自动打标签
- [ ] 无 API Key → 标签任务跳过，不崩溃
- [ ] 编辑文字后 → 重新打标签
- [ ] 纯图记录 → 视觉识别 + 标签
- [ ] 网络断开 → Worker 重试
- [ ] 编辑与 AI 并发 → 用户编辑不丢失

## 搜索与筛选

- [ ] 搜索关键词 → 实时过滤
- [ ] 关闭搜索 → 筛选条件重置
- [ ] 标签筛选 → 多选组合过滤
- [ ] 图片筛选 → 三态切换（全部/有图/无图）
- [ ] "清除筛选" → 恢复全部显示

## 周/月总结

- [ ] 周一 → "总结上周"按钮可用
- [ ] 每月 1 号 → "总结上月"按钮可用
- [ ] 非生成日 → 按钮隐藏
- [ ] 生成结果保存为 SUMMARY 类型
- [ ] 重新生成 → 覆盖同周期已有总结
- [ ] 不足 3 条 → 提示无法生成

## 回忆页

- [ ] 随机回顾卡片显示内容和标签
- [ ] "再抽一条" 换记录
- [ ] 卡片高度自适应（短内容不空，长内容可滚动）
- [ ] 历史总结列表显示
- [ ] 总结卡显示时间范围和模型

## 回收站

- [ ] 删除记录 → 移至回收站（不立即删除）
- [ ] 回收站可恢复 → 标签完整保留
- [ ] 回收站可清空 → 图片文件同步清理
- [ ] 永久删除确认弹窗

## 导入导出

- [ ] 导出为 .gtlbackup ZIP → 含 manifest.json + images/
- [ ] 导入 v2 ZIP → 数据完整恢复
- [ ] 导入 v1 JSON → 兼容旧格式，提示缺少元数据
- [ ] 损坏备份 → 拒绝导入，数据库不受影响
- [ ] 导入前确认弹窗 → "将清空现有记录"
- [ ] 模型配置导入导出 → API Key 除外

## 分享与 Widget

- [ ] 其他 App 分享文字 → 自动填入输入区
- [ ] 其他 App 分享图片 → 显示缩略图
- [ ] Widget 点击 → 打开 App
- [ ] App 前台再次分享 → 即时更新

## 隐私与安全

- [ ] API Key 不随系统云备份
- [ ] 设置页面 model 配置导出不含 API Key

## 性能

- [ ] 1000 条记录列表滚动流畅
- [ ] Release APK < 8 MiB

## 无障碍

- [ ] 所有可点击图标有 contentDescription
- [ ] 点击区域 ≥ 48dp
